## 预览和配置

- Word 和 PPT 首先使用管理员按格式配置的转换器，其次调用匠宝 Host 的 `officeToPdf.convert()`。普通 Profile 或独立 MCP 可用 `documentPreview.office` 指定外部程序。下载前校验库及文档归属，并限制为平台同源地址。重复打开仍校验授权并读取原件来确定版本。
- Excel 通过 authenticated Connection 分段取字节，Worker 按需解析。已验证真实 BIFF8 XLS 和 OOXML XLSX 的工作表切换、中文、数字和日期格式、合并单元格、公式缓存值、翻组和滚动。单独检查了真实加密 XLSX 的密码提示。合成的 20,000 行、12 列 XLSX 可解析，20,001 行样本返回超限。
- PDF.js 原生 PDF、Markdown、纯文本、知识库检索、引用导航和切片查看均通过回归。WPS、DPS、DPSX、OFD 分别使用同扩展名的专用转换器。缺少组件时保留目录及切片入口并显示提示。HTML、MHTML 和图片的原有转换路由可由管理员配置外部程序。
- 升级读取原配置，保留凭据、业务参数、外部程序路径和明确关闭的预览开关。新装从包内模板自动初始化。普通卸载仍保留配置。Word/PPT 和 Excel 由插件分别通过匠宝 Host 与浏览器 Worker 处理。 [安装、升级和配置](使用与维护手册.md#安装与升级)

## 自动验证与内网待验

- 通过类型检查、构建、自动测试、Chrome 预览界面测试和离线包校验。自动测试也覆盖授权失配、转换服务缺失、失败、共享请求取消、变更版本、缓存失效及诊断脱敏。外部转换分支用现有 LibreOffice 实测。
