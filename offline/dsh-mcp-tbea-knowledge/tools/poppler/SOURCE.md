# Poppler 来源

本目录来自 Windows x64 上已安装的 Codex Primary Runtime，保留其中的 `Library`、`share` 和原始 `manifest.json`。Poppler 版本为 26.07.0，清单记录的构建为 `poppler=26.07.0=h6618ce5_3`。

- [Poppler 26.07.0 原始源码](https://poppler.freedesktop.org/poppler-26.07.0.tar.xz)
- [conda-forge Poppler 构建配方和补丁](https://github.com/conda-forge/poppler-feedstock)
- [同版本 Windows 构建包及其许可证目录](https://anaconda.org/conda-forge/poppler/files?version=26.07.0)
- [Poppler 编码数据和源码](https://poppler.freedesktop.org/)
