# 2026-11-03 来源选择与预检索更新

本文保留0.2.0的历史记录。现用版本的安装和入口见《使用教程.md》，内网验证结果见《验证记录.md》。以下快捷入口和静态清单说明仅对应历史版本。

展示插件版本：`0.2.0`；目标 Harness 版本仍为 `0.2.2-alpha.2`。

## 使用行为

- 在 `+` 菜单或 `@` 候选中选择“公司知识库”，无需选择具体库。
- 输入框上方显示“公司知识库 ×”，同一会话持续生效，直到手动取消；新会话默认未选中。
- 选中时，程序先通过真实 MCP 检索 `config/local.json` 中登记的全部知识库，再将文字证据交给模型。失败或停止时不放行本次模型回答。
- 取消后仍保留模型自动检索；自动调用的决定仍由模型作出。
- 来源展开、切片详情、表格与图片预览继续可用。程序预检索的来源记录写入会话上下文，模型自动检索仍使用原工具结果卡片。
- 知识库继续使用 JSON 管理，没有新增管理界面。参见《知识库配置.md》。

## 更新到已有环境

推荐将更新后的源码工程或离线运行包复制到内网，保留原有的 `config/local.json`、`data`，不要用初始化示例覆盖正式 AK/SK 和库 ID。使用的运行目录未移动时，既有配置路径继续有效。

停止知识服务，完全退出 DSH Desktop，更新程序文件；从 DSH 托盘打开终端，在项目根目录重新运行 `Install-Plugin.ps1`，然后启动服务并重启 DSH。完整命令见《使用教程》。

`offline/dsh-mcp-tbea-knowledge` 和对应 ZIP 默认不包含本地凭证与数据，首次复制到新目录后需执行初始化并填写配置。

本次只修改知识库 MCP/展示插件项目，未修改 `AIStudio_Electron` 匠宝客户端。目标交付目录的既有 `local.json` 和 `data` 保留。
