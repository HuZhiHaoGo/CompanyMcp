# 匠宝知识库插件卸载、MCP 关停与数据清理

本文适用于知识库插件 0.5.0。匠宝源码使用 Harness `0.2.2-rc.1` 和 `desktop` Profile。以下脚本从知识库插件的项目或离线运行目录执行。请使用与匠宝实际安装对应的那份 `config/local.json`。

## 1. 暂停或关闭 MCP

| 你的目的 | 操作 | 生效范围 |
| --- | --- | --- |
| 暂停匠宝当次运行的 MCP | 运行 `Stop-Service.ps1` | 关停匠宝托管的监听服务。当前插件实例保持暂停，重新启动匠宝后按现有配置启动 |
| 停止管理员独立启动的 MCP | 在原窗口按 `Ctrl+C`，或运行 `Stop-Service.ps1 -Manual` | 仅关闭当前配置所对应的独立服务 |
| 让以后启动匠宝时不自动创建 MCP | 运行 `Set-ServiceAutoStart.ps1 -Mode Disable`，再从托盘完全退出并打开匠宝 | 写入 `service.autoStart=false`，重启后生效。管理员仍可手动启动独立 MCP |
| 恢复随匠宝启动 | 运行 `Set-ServiceAutoStart.ps1 -Mode Enable`，再完全重启匠宝 | 恢复 `service.autoStart=true` |

```powershell
# 暂停一次匠宝托管的 MCP
powershell -ExecutionPolicy Bypass -File .\scripts\Stop-Service.ps1

# 显式关停独立 MCP
powershell -ExecutionPolicy Bypass -File .\scripts\Stop-Service.ps1 -Manual

# 禁止下次自动启动
powershell -ExecutionPolicy Bypass -File .\scripts\Set-ServiceAutoStart.ps1 -Mode Disable
```

关停前核对本机服务、服务口令、配置身份和运行方式。服务接受关停后，脚本等待端口释放。匠宝本体保持打开，正在进行的 MCP 调用会被中断。旧包没有关停接口时，关闭托盘中的匠宝可停止托管服务，关闭手动服务用原窗口的 `Ctrl+C`。普通关闭聊天窗口可能只是隐藏到托盘。

## 2. 卸载插件并保留数据

- **内网匠宝默认使用 `desktop` Profile**。在匠宝的「插件管理 → 已安装」中找到知识库插件并选择卸载，再从托盘完全退出并重启。匠宝负责更新插件清单及加载状态。若希望退出匠宝前先关闭它托管的 MCP，可单独运行 `Stop-Service.ps1`。
- **普通 Harness Profile 中通过 CLI 安装的本地插件**，在提供对应 `dsh` 的终端运行以下命令。把 `web` 换成安装时使用的普通 Profile。匠宝保留的 `desktop` Profile 使用上一条界面流程。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Uninstall-Plugin.ps1 -Profile web
```

普通 Profile 脚本通过 `dsh plugin remove` 移除 `dsh-plugin-tbea-knowledge`，随后尝试关停同一配置的托管 MCP。独立 MCP 继续由管理员控制。若脚本提示插件已移除但服务未确认关停，完全退出对应应用，再重启确认“公司知识库”入口和工具已移除。如曾手动给 Profile 添加本插件的覆盖条目，用宿主的 Profile 管理去掉对应条目。

卸载保留项目目录、`config/local.json`、已查看的来源缓存和会话知识库开关。日后在原目录用同一 Profile 重新安装，插件可以继续读取这些数据。

## 3. 单独清理本地知识数据

先从托盘完全退出匠宝，并关停用同一配置启动的独立 MCP。建议先预览：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Clear-LocalData.ps1 -WhatIf
```

实际清理缓存及会话开关，操作时会要求确认：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Clear-LocalData.ps1
```

连同 `config/local.json` 一并清理时，显式加 `-IncludeConfig`。这会移除其中的凭证、项目和启动设置，重装后需要重新填写。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Clear-LocalData.ps1 -IncludeConfig
```

如果 `local.json` 指向自定义缓存目录，须另传 `-DataDirectory "F:\实际缓存目录"`，且绝对路径要和配置一致。清理只识别本插件的快照、带图片元数据的缓存文件和选中状态文件。若配置端口仍有服务，脚本会拒绝清理。遇到符号链接、目录联接或无法识别的文件时，保留这些内容供管理员核对。

清理后匠宝已有的聊天正文仍可查看。引用卡片依赖的本地缓存一旦清除，旧引用可能无法再次展开。
