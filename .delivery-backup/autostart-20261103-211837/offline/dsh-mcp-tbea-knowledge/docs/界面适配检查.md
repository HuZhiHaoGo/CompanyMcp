# DSH 界面风格与交互检查

展示插件版本：0.2.1。依据 Harness 0.2.2-alpha.2，固定提交 f3803c96974ad4a94195fb97e5c637e9c2a3afe3 中的 ui-theme、Button、PlanChip、DisclosureRow 和图片预览样式。

## 检查发现及修正

| 原问题 | 本次修正 |
| --- | --- |
| 独立蓝灰配色、固定微软雅黑，与宿主主题和字体设置可能不一致 | 消费 DSH 的 --dsw-alias-*、--dsw-font-family 和 --dsh-content-font-* 变量 |
| 以系统深色偏好切换，无法正确跟随用户手动选择的 DSH 主题 | 跟随 DSH 的主题变量及 body[data-ds-dark-theme]，不以 prefers-color-scheme 覆盖 |
| 同类图标按钮和图标尺寸不同 | 普通操作按钮统一28×28px，内图标16×16px，圆角使用宿主 sm；来源标签高度28px，标签内关闭区域24px |
| 文件名与长引用编号挤在同一行 | 文件名独占主要宽度，最多显示两行；引用编号移到元信息行，全文保留在悬停提示及切片详情中 |
| 正文换行较多时可能截断且没有展开按钮 | 多行短文本也提供展开；短文本不再无条件截断 |
| 弹窗写死图片区域高度，标题换行后可能遮挡工具栏 | 改用弹性布局，图片首次展示按宽高共同适配窗口 |
| 关闭按钮、放大、下载等图标视觉大小不一 | 弹窗工具与卡片操作使用相同图标尺寸，显示相对适配尺寸的缩放比例 |
| 键盘焦点可能移出弹窗、复制反馈弱 | Tab/Shift+Tab 保持在弹窗，Esc关闭并回到原图片；复制后显示勾选及无障碍状态反馈 |
| 原始 JSON 错误不便阅读 | 工具错误优先展示可读 message；图片失败保留明确提示及重试入口 |

正式 DSH 的 + 和 @ 候选列表仍由原生菜单渲染。独立 demo 的菜单只演示行为，不是完整 DSH 实机界面。插件不写入宿主主题变量，也不修改 DSH 原生按钮。

## 已执行验证

- 浅色与深色，分别在1280×900及390×844检查；故意设置相反的系统主题偏好，确认手动界面主题仍有效。
- 320×700窗口配合22px内容字号，检查控件、长文本、表格、图片和弹窗工具栏；页面无横向溢出。
- 实测同类图标按钮28×28px、内部图标16×16px，来源标签28px；自定义宿主强调色可以即时生效。
- 来源开合、选择/取消、重载保留、复制、切片详情、图片适配/缩放、Esc关闭、焦点恢复和键盘正反向循环。
- 超长文档标题、短多行文字、图片失败/重试及空结果。
- 原有17项自动化回归测试通过。

相关截图在 test-results：desktop.png、desktop-dark.png、mobile.png、mobile-dark.png、compact-large-font.png，以及对应的 -image 和 -selection 截图。

## 修改文件

- plugin/src/style.css：主题、字号、间距、尺寸和响应式布局。
- plugin/src/client.jsx：长内容展示、复制反馈、无障碍属性及图片预览交互。
- plugin/package.json：展示插件版本更新为0.2.1。
- demo/entry.jsx、demo/style.css：浅深主题预览，演示页使用对应主题样本。
- scripts/verify-ui.mjs：扩展主题、字号、几何尺寸、焦点与异常状态检查。
- README.md、plugin/README.md、docs/验证记录.md及本文：同步说明。
- plugin/lib、dist/demo、test-results、offline目录及ZIP：对应构建和交付产物。

目标交付目录的 config/local.json、data 及插件配置保留。
